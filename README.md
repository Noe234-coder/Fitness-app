# FitnessApp

Web app (PWA) for a personal trainer and his athletes: workout plans with set logging that works offline,
meal plans, daily check-ins (weight, steps, sleep, stress) and progress charts. Spanish first, English too.

- **Rules for Claude Code:** [CLAUDE.md](CLAUDE.md)
